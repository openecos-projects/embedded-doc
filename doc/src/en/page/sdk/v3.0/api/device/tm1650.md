# TM1650 Seven-Segment Display

A four-digit seven-segment display driven by GPIO bit-banging.

- Header: `ecos/device/tm1650.h`
- Bus: GPIO (data line + clock line)
- Example: `examples/peripherals/gpio/tm1650`

## Types and Constants

```c
#define ECOS_TM1650_POSITION_COUNT 4u     /* 4 digits */
#define ECOS_TM1650_SEGMENT_DOT 0x80u     /* decimal point position (bit7 = DP) */
#define ECOS_TM1650_BRIGHTNESS_OFF 0u     /* display off */
#define ECOS_TM1650_BRIGHTNESS_MAX 8u
#define ECOS_TM1650_BRIGHTNESS_DEFAULT 3u

typedef struct {
    ecos_gpio_port_t dat_port;  /* data line pin */
    uint8_t dat_pin;
    ecos_gpio_port_t clk_port;  /* clock line pin */
    uint8_t clk_pin;
} ecos_tm1650_config_t;

typedef struct {
    ecos_tm1650_config_t config;
    uint8_t brightness;
    uint8_t initialized;
} ecos_tm1650_t;

/* StarrySky L4C1 onboard wiring: SEG_DAT = GPIO1[9], SEG_CLK = GPIO1[10] */
#define ECOS_TM1650_CONFIG_DEFAULT { ECOS_GPIO_PORT_1, 9u, ECOS_GPIO_PORT_1, 10u }
```

## Functions

```c
ecos_err_t ecos_tm1650_init(ecos_tm1650_t *display,
                            const ecos_tm1650_config_t *config);
ecos_err_t ecos_tm1650_deinit(ecos_tm1650_t *display);
ecos_err_t ecos_tm1650_set_brightness(ecos_tm1650_t *display, uint8_t level);
ecos_err_t ecos_tm1650_clear(ecos_tm1650_t *display);
ecos_err_t ecos_tm1650_set_segments(ecos_tm1650_t *display, uint8_t position,
                                    uint8_t segments);
ecos_err_t ecos_tm1650_show_digit(ecos_tm1650_t *display, uint8_t position,
                                  uint8_t value, bool dot);
ecos_err_t ecos_tm1650_show_number(ecos_tm1650_t *display, uint16_t value,
                                   bool leading_zero);
```

| Function | Description |
| --- | --- |
| `ecos_tm1650_init()` | Configure GPIO, clear all digits, and light the display at the default brightness |
| `ecos_tm1650_deinit()` | Turn off the display and release the handle |
| `ecos_tm1650_set_brightness()` | `level` 0 turns the display off; 1..8 selects the duty cycle |
| `ecos_tm1650_clear()` | Clear all digits |
| `ecos_tm1650_set_segments()` | Write a raw segment pattern: bit0=A … bit6=G, bit7=DP; `position` 0 = DIG1 … 3 = DIG4 |
| `ecos_tm1650_show_digit()` | Display one hexadecimal digit (0-15); `dot` controls the decimal point |
| `ecos_tm1650_show_number()` | Display 0-9999 as unsigned decimal, right-aligned; when `leading_zero` is true, leading positions are zero-padded |

## Usage Example

```c
#include "ecos/device/tm1650.h"

void show_value(uint16_t value)
{
    ecos_tm1650_t display;

    ecos_tm1650_init(&display, &(const ecos_tm1650_config_t)
                     ECOS_TM1650_CONFIG_DEFAULT);
    ecos_tm1650_set_brightness(&display, 5u);
    ecos_tm1650_show_number(&display, value, false);

    /* Display a raw segment pattern: segments A, B, C of DIG1 */
    ecos_tm1650_set_segments(&display, 0u, 0x07u);
}
```

## Notes

- `init` configures GPIO, clears all digits, and lights the display at `ECOS_TM1650_BRIGHTNESS_DEFAULT`.
- Bit-bang timing is handled by the GPIO driver; do not reuse the same DAT/CLK pin pair in other code.
- A `position` outside 0..3 returns `ECOS_ERR_INVALID_ARGUMENT`.
- For low-level pin control, see [GPIO driver](../driver/gpio.md).
