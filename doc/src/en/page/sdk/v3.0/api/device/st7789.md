# ST7789 TFT Display

A 240×240 QSPI TFT display driver, fully isomorphic to [ST7735](st7735.md).

- Header: `ecos/device/st7789.h`
- Bus: QSPI + GPIO (D/C, RST, BLK)
- Example: `examples/peripherals/spi_master/st7789`

## Types and Constants

```c
typedef struct {
    ecos_qspi_id_t qspi;             /* QSPI controller instance */
    ecos_qspi_cs_t chip_select;      /* chip select */
    ecos_gpio_port_t dc_port;        /* D/C pin */
    uint8_t dc_pin;
    ecos_gpio_port_t reset_port;     /* reset pin */
    uint8_t reset_pin;
    ecos_gpio_port_t backlight_port; /* backlight pin */
    uint8_t backlight_pin;
    uint16_t width;                  /* panel width (pixels) */
    uint16_t height;                 /* panel height (pixels) */
    uint8_t rotation;                /* rotation */
    uint8_t horizontal_offset;       /* memory horizontal offset */
    uint8_t vertical_offset;         /* memory vertical offset */
    uint32_t qspi_clock_divider;     /* QSPI clock divider */
} ecos_st7789_config_t;

typedef struct {
    ecos_st7789_config_t config;
    uint8_t initialized;
} ecos_st7789_t;

#define ECOS_ST7789_CONFIG_DEFAULT \
    { ECOS_QSPI_DEFAULT, ECOS_QSPI_CS_0, ECOS_GPIO_PORT_0, 29u, \
      ECOS_GPIO_PORT_0, 30u, ECOS_GPIO_PORT_0, 31u, \
      240u, 240u, 0u, 0u, 0u, 3u }
```

## Functions

```c
ecos_err_t ecos_st7789_init(ecos_st7789_t *display,
                            const ecos_st7789_config_t *config);
ecos_err_t ecos_st7789_deinit(ecos_st7789_t *display);
ecos_err_t ecos_st7789_set_window(ecos_st7789_t *display,
                                  uint16_t x, uint16_t y,
                                  uint16_t width, uint16_t height);
ecos_err_t ecos_st7789_fill(ecos_st7789_t *display,
                            uint16_t x, uint16_t y,
                            uint16_t width, uint16_t height,
                            uint32_t color);
```

The function semantics correspond one-to-one with [ST7735](st7735.md); only the default panel parameters differ (240×240).

## Usage Example

```c
#include "ecos/board_resources.h"
#include "ecos/device/st7789.h"

void clear_screen(void)
{
    ecos_st7789_t display;
    const ecos_st7789_config_t config = {
        .qspi = ECOS_BOARD_QSPI_BUS_CONTROLLER,
        .chip_select = ECOS_BOARD_DISPLAY_CHIP_SELECT,
        .dc_port = ECOS_BOARD_DISPLAY_DC_PORT,
        .dc_pin = ECOS_BOARD_DISPLAY_DC_PIN,
        .reset_port = ECOS_BOARD_DISPLAY_RESET_PORT,
        .reset_pin = ECOS_BOARD_DISPLAY_RESET_PIN,
        .backlight_port = ECOS_BOARD_DISPLAY_BACKLIGHT_PORT,
        .backlight_pin = ECOS_BOARD_DISPLAY_BACKLIGHT_PIN,
        .width = ECOS_BOARD_DISPLAY_WIDTH,
        .height = ECOS_BOARD_DISPLAY_HEIGHT,
        .rotation = ECOS_BOARD_DISPLAY_ROTATION,
        .horizontal_offset = ECOS_BOARD_DISPLAY_HORIZONTAL_OFFSET,
        .vertical_offset = ECOS_BOARD_DISPLAY_VERTICAL_OFFSET,
        .qspi_clock_divider = ECOS_BOARD_QSPI_BUS_CLOCK_DIVIDER,
    };

    ecos_st7789_init(&display, &config);
    ecos_st7789_fill(&display, 0u, 0u, config.width, config.height,
                     0x00000000u); /* black */
}
```

## Notes

- `color` is likewise two packed RGB565 pixels, with the high 16 bits sent first.
- The display resource is selected by panel model: ST7735 uses `display`, ST7789 uses `display-st7789`; the generator outputs the same set of `ECOS_BOARD_DISPLAY_*` macros for both.
- RST/BLK ports not connected to a controllable GPIO use `ECOS_GPIO_PORT_COUNT`; the driver skips that port and will not output levels to an arbitrary placeholder pin.
- Depends on the QSPI frame-write interface; the Target restrictions are the same as for ST7735.
- You can also use the unified interface of [BSP Display](../bsp.md#bsp-display).
