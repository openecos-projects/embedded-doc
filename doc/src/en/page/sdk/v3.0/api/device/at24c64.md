# AT24C64 EEPROM

An 8 KB EEPROM with an I2C interface; the driver automatically handles 32-byte page boundaries and the internal write cycle.

- Header: `ecos/device/at24c64.h`
- Bus: I2C
- Example: `examples/peripherals/i2c/at24c64`

## Types and Constants

```c
#define ECOS_AT24C64_I2C_ADDRESS 0x50u    /* 7-bit address with A2/A1/A0 grounded */
#define ECOS_AT24C64_CAPACITY_BYTES 8192u /* 8 KB capacity */
#define ECOS_AT24C64_PAGE_BYTES 32u       /* 32-byte page size */

typedef struct {
    ecos_i2c_id_t i2c;
    uint8_t address;
} ecos_at24c64_config_t;

typedef struct {
    ecos_at24c64_config_t config;
    uint8_t initialized;
} ecos_at24c64_t;

#define ECOS_AT24C64_CONFIG_DEFAULT { ECOS_I2C_DEFAULT, ECOS_AT24C64_I2C_ADDRESS }
```

## Functions

```c
ecos_err_t ecos_at24c64_init(ecos_at24c64_t *eeprom,
                             const ecos_at24c64_config_t *config);
ecos_err_t ecos_at24c64_deinit(ecos_at24c64_t *eeprom);
ecos_err_t ecos_at24c64_read(ecos_at24c64_t *eeprom, uint16_t memory_address,
                             void *data, size_t size);
ecos_err_t ecos_at24c64_write(ecos_at24c64_t *eeprom, uint16_t memory_address,
                              const void *data, size_t size);
```

| Function | Description |
| --- | --- |
| `ecos_at24c64_init()` | Initialize and probe the device address; the I2C controller must be initialized first |
| `ecos_at24c64_deinit()` | Deinitialize the handle |
| `ecos_at24c64_read()` | Read `size` bytes from `memory_address` |
| `ecos_at24c64_write()` | Write `size` bytes to `memory_address` |

## Usage Example

```c
#include "ecos/device/at24c64.h"
#include "ecos/driver/i2c.h"

#define LOG_TAG "eeprom"

static ecos_at24c64_t eeprom;

void store_config(const void *data, size_t size)
{
    const ecos_i2c_config_t bus = ECOS_I2C_CONFIG_DEFAULT;

    ecos_i2c_init(ECOS_I2C_DEFAULT, &bus);
    ecos_at24c64_init(&eeprom, &(const ecos_at24c64_config_t)
                      ECOS_AT24C64_CONFIG_DEFAULT);
    ecos_at24c64_write(&eeprom, 0u, data, size);
}
```

## Notes

- `init` probes the device address; if the address pins are wired differently, change `address` in config.
- `ecos_at24c64_write()` automatically splits writes at 32-byte page boundaries and waits for the internal write cycle to complete after each page, so the application does not need to care about paging.
- `memory_address` ranges from 0 to 8191; cross-page writes are split by the driver, but the application must still ensure that the start address falls within the valid range.
- EEPROM has a limited write endurance; avoid high-frequency writes in loops.
- For the generic I2C interface, see [I2C master driver](../driver/i2c.md).
