# ST7735 TFT Display

A 128×128 QSPI TFT display driver providing window setting and rectangle fill.

- Header: `ecos/device/st7735.h`
- Bus: QSPI + GPIO (D/C, RST, BLK)
- Example: `examples/peripherals/spi_master/st7735`

## Types and Constants

```c
typedef struct {
    ecos_qspi_id_t qspi;             /* QSPI controller instance */
    ecos_qspi_cs_t chip_select;      /* chip select */
    ecos_gpio_port_t dc_port;        /* D/C pin (command/data select) */
    uint8_t dc_pin;
    ecos_gpio_port_t reset_port;     /* reset pin */
    uint8_t reset_pin;
    ecos_gpio_port_t backlight_port; /* backlight pin */
    uint8_t backlight_pin;
    uint16_t width;                  /* panel width (pixels) */
    uint16_t height;                 /* panel height (pixels) */
    uint8_t rotation;                /* rotation */
    uint8_t horizontal_offset;       /* memory horizontal offset */
    uint8_t vertical_offset;         /* memory vertical offset */
    uint32_t qspi_clock_divider;     /* QSPI clock divider */
} ecos_st7735_config_t;

typedef struct {
    ecos_st7735_config_t config;
    uint8_t initialized;
} ecos_st7735_t;

#define ECOS_ST7735_CONFIG_DEFAULT \
    { ECOS_QSPI_DEFAULT, ECOS_QSPI_CS_0, ECOS_GPIO_PORT_0, 29u, \
      ECOS_GPIO_PORT_0, 30u, ECOS_GPIO_PORT_0, 31u, \
      128u, 128u, 0u, 0u, 0u, 3u }
```

## Functions

```c
ecos_err_t ecos_st7735_init(ecos_st7735_t *display,
                            const ecos_st7735_config_t *config);
ecos_err_t ecos_st7735_deinit(ecos_st7735_t *display);
ecos_err_t ecos_st7735_set_window(ecos_st7735_t *display,
                                  uint16_t x, uint16_t y,
                                  uint16_t width, uint16_t height);
ecos_err_t ecos_st7735_fill(ecos_st7735_t *display,
                            uint16_t x, uint16_t y,
                            uint16_t width, uint16_t height,
                            uint32_t color);
```

| Function | Description |
| --- | --- |
| `ecos_st7735_init()` | Initialize QSPI, D/C, RST, and BLK and perform the panel initialization sequence |
| `ecos_st7735_deinit()` | Turn off the backlight and release the handle |
| `ecos_st7735_set_window()` | Set the rectangular window for subsequent pixel writes |
| `ecos_st7735_fill()` | Fill a rectangle with a packed RGB565 color |

## Usage Example

```c
#include "ecos/board_resources.h"
#include "ecos/device/st7735.h"
#include "ecos/log.h"

#define LOG_TAG "display"

void fill_screen(void)
{
    ecos_st7735_t display;
    const ecos_st7735_config_t config = {
        .qspi = ECOS_BOARD_QSPI_BUS_CONTROLLER,
        .chip_select = ECOS_BOARD_DISPLAY_CHIP_SELECT,
        .dc_port = ECOS_BOARD_DISPLAY_DC_PORT,
        .dc_pin = ECOS_BOARD_DISPLAY_DC_PIN,
        .reset_port = ECOS_BOARD_DISPLAY_RESET_PORT,
        .reset_pin = ECOS_BOARD_DISPLAY_RESET_PIN,
        .backlight_port = ECOS_BOARD_DISPLAY_BACKLIGHT_PORT,
        .backlight_pin = ECOS_BOARD_DISPLAY_BACKLIGHT_PIN,
        .width = ECOS_BOARD_DISPLAY_WIDTH,
        .height = ECOS_BOARD_DISPLAY_HEIGHT,
        .rotation = ECOS_BOARD_DISPLAY_ROTATION,
        .horizontal_offset = ECOS_BOARD_DISPLAY_HORIZONTAL_OFFSET,
        .vertical_offset = ECOS_BOARD_DISPLAY_VERTICAL_OFFSET,
        .qspi_clock_divider = ECOS_BOARD_QSPI_BUS_CLOCK_DIVIDER,
    };

    ecos_st7735_init(&display, &config);
    ecos_st7735_fill(&display, 0u, 0u,
                     config.width, config.height, 0xF800F800u); /* red */
}
```

## Notes

- During `init`, the RST and backlight pins are each driven high once.
- `color` in `ecos_st7735_fill()` is **two packed RGB565 pixels** (high 16 bits sent first), for example red `0xF800F800u`; it fills `(w×h)/2` 32-bit words.
- When porting, prefer filling config with the `ECOS_BOARD_DISPLAY_*` macros from `ecos/board_resources.h`; do not hard-code pins.
- For RST/BLK that are fixed wiring, the resource macros use `ECOS_GPIO_PORT_COUNT`, and the driver skips that pin.
- Depends on the QSPI frame-write interface; unavailable on Targets that only support command/address transactions (such as T1-Pico), see [QSPI driver](../driver/qspi.md).
- You can also use the unified interface of [BSP Display](../bsp.md#bsp-display) without operating this driver directly.
