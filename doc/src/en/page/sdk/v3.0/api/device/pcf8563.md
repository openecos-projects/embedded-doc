# PCF8563 RTC

An I2C calendar RTC chip providing second/minute/hour/day/weekday/month/year fields.

- Header: `ecos/device/pcf8563.h`
- Bus: I2C
- Example: `examples/peripherals/i2c/pcf8563`

## Types and Constants

```c
#define ECOS_PCF8563_I2C_ADDRESS 0x51u

typedef struct {
    ecos_i2c_id_t i2c;
    uint8_t address;
} ecos_pcf8563_config_t;

typedef struct {
    ecos_pcf8563_config_t config;
    uint8_t initialized;
} ecos_pcf8563_t;

typedef struct {
    uint8_t second;   /* 0-59 */
    uint8_t minute;   /* 0-59 */
    uint8_t hour;     /* 0-23 */
    uint8_t day;      /* 1-31 */
    uint8_t weekday;  /* 0-6 */
    uint8_t month;    /* 1-12 */
    uint8_t year;     /* 0-99, offset relative to year 2000 */
} ecos_pcf8563_time_t;

#define ECOS_PCF8563_CONFIG_DEFAULT { ECOS_I2C_DEFAULT, ECOS_PCF8563_I2C_ADDRESS }
```

## Functions

```c
ecos_err_t ecos_pcf8563_init(ecos_pcf8563_t *rtc,
                             const ecos_pcf8563_config_t *config);
ecos_err_t ecos_pcf8563_deinit(ecos_pcf8563_t *rtc);
ecos_err_t ecos_pcf8563_get_time(ecos_pcf8563_t *rtc, ecos_pcf8563_time_t *time);
ecos_err_t ecos_pcf8563_set_time(ecos_pcf8563_t *rtc,
                                 const ecos_pcf8563_time_t *time);
```

| Function | Description |
| --- | --- |
| `ecos_pcf8563_init()` | Only probes the device, does not touch the RTC registers |
| `ecos_pcf8563_deinit()` | Deinitialize the handle |
| `ecos_pcf8563_get_time()` | Read the current date and time |
| `ecos_pcf8563_set_time()` | Set the date and time |

## Usage Example

```c
#include "ecos/device/pcf8563.h"
#include "ecos/driver/i2c.h"
#include "ecos/log.h"

#define LOG_TAG "rtc"

void read_clock(void)
{
    ecos_pcf8563_t rtc;
    ecos_pcf8563_time_t now;
    const ecos_pcf8563_config_t config = ECOS_PCF8563_CONFIG_DEFAULT;

    ecos_i2c_init(ECOS_I2C_DEFAULT, &(const ecos_i2c_config_t)ECOS_I2C_CONFIG_DEFAULT);
    ecos_pcf8563_init(&rtc, &config);

    if (ecos_pcf8563_get_time(&rtc, &now) == ECOS_OK)
        (void)ECOS_LOGI(LOG_TAG, "20%02u-%02u-%02u %02u:%02u:%02u",
                        now.year, now.month, now.day,
                        now.hour, now.minute, now.second);
}
```

## Notes

- `init` only probes the device and does not touch the RTC registers (so it will not disturb a clock that is running).
- The time fields have decimal semantics; the driver performs the BCD conversion internally; `year` is the offset relative to 2000.
- The counter/alarm interface of the on-chip RTC is a different IP; see [RTC driver](../driver/rtc.md).
- For the generic I2C interface, see [I2C master driver](../driver/i2c.md).
