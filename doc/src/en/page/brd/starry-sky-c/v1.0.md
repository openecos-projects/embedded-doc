# Getting Started

## Project Overview

The main control chip of the StarrySky C1 board is the team's self-developed [retroSoC](https://github.com/retroSoC/retroSoC). **It is an open-source ASIC customization framework that supports integrating different types of open-source RISC-V processor cores (self-developed or third-party) and facilitates tape-out.** The current version of retroSoC integrates the well-known open-source RISC-V processor core [PicoRV32](https://github.com/YosysHQ/picorv32) from abroad. It fully implements the RV32IMC instruction set and can be flexibly configured into various combinations such as RV32E, RV32I, RV32IC, RV32IM, and RV32IMC. In addition, **retroSoC also includes many open-source peripheral modules, such as UART, SPI, I2C, GPIO, PWM, and LCD, enabling fairly rich demonstration effects.** Finally, overall, the board's main control chip is roughly equivalent in functionality and performance to ST's F1 mid-to-low-end series. However, due to possible software and hardware errors, the board is currently intended only for embedded prototyping (e.g., internal testing, participation in competitions), and must not be used in actual production environments.

## Chip Introduction

### Hardware Architecture

- **Processor Core**: PicoRV32
- **Instruction Set Architecture**: RISC-V rv32imac
- **Operating Frequency**: 72MHz

### Memory System

- **On-chip SRAM**: 128KB @ 0x00000000-0x0001FFFF
- **External PSRAM**: 8MB @ 0x04000000-0x047FFFFF (1x8MB)
- **SPI Flash**: 16MB @ 0x30000000-0x30FFFFFF

### Peripheral Modules

The project includes a rich set of peripheral driver modules:

#### Communication Interfaces

- **UART**: standard serial communication (115200 8N1)
- **UART(HP)**: high-performance serial port
- **SPI**: standard SPI interface
- **HK SPI**: dedicated SPI controller
- **I2C**: I2C bus interface
- **PS2**: PS2 keyboard/mouse interface

#### Storage and Control

- **GPIO**: 16 general-purpose input/output lines
- **PWM**: 4 pulse-width modulation outputs
- **Timer**: 2 timers (TIM0, TIM1)
- **Flash**: SPI Flash controller
- **PSRAM**: external PSRAM controller

#### Others

- **RNG**: random number generator
- **ArchInfo**: system architecture information

## Board Introduction

![](../../../res/img/brd/starry-sky-c/v1.0/brd_func_top.webp)

The peripheral interfaces of the StarrySky C1 are described below:

- System:
    - 1 power switch, red power indicator LED
    - 1 Type-C power interface (also serves as the SoC's UART debug interface)
    - 1 drag-and-drop programmer: HFP-LINK
- SoC:
    - 1 24 MHz active crystal oscillator
    - 1 active crystal oscillator pad position
    - 1 UART debug interface, using a CP2102 for protocol conversion
    - 1 4-position CLK configuration DIP switch
    - 1 reset button
    - 1 PS2 interface
    - 1 8MB PSRAM
    - 1 128Mbit SPI Flash
    - 5 IO pin breakouts

## Power-On Test

A baseline test is performed before the board is shipped, so the FLASH stores a simple test program used to check whether the board works properly.

- **Notes**
    - Set the mode selection switch to CHIP
    - The clock configuration DIP switch should be 0100 from left to right
- **Power-on**
    - Connect the Type-C debug interface (for UART debugging)
    - Turn on the power switch
    - Check whether the red power indicator LED is lit
- **Test**
    - Open a serial terminal (e.g., Tabby)
    - Configure the baud rate to 115200, 8 data bits, no parity, 1 stop bit
    - Check whether information is output correctly

## Development Workflow

1. Development environment setup
    - Refer to the [ECOS-SDK repository](https://github.com/openecos-projects/embedded-sdk)

2. Flashing procedure
    - Connect the board to the PC using a USB cable
    - Set the FLASH_SEL switch to MCU
    - Turn on the board power
    - Drag the compiled bin file into the HFP-LINK window
    - Wait for LED4 to stop blinking, and check whether the status file in the HFP-LINK window shows Success
    ![](../../../res/img/brd/starry-sky-c/v1.0/link_download.webp)

3. Starting the board
    - With the power off, set the FLASH_SEL switch to chip
    - Turn on the board power
    - Check whether the red power indicator LED is lit
    - Open a serial terminal (e.g., Tabby) and configure the baud rate to 115200, 8 data bits, no parity, 1 stop bit
    - Press the reset button and check whether information is output correctly
