# Getting Started

## Project Overview

The main control chip of the StarrySky C2 board uses the team's self-developed [retroSoC](https://github.com/retroSoC/retroSoC). It is an open-source ASIC customization framework that supports integrating different types of open-source RISC-V processor cores (self-developed or third-party) and facilitates tape-out. The current version of retroSoC integrates the well-known open-source RISC-V processor core [PicoRV32](https://github.com/YosysHQ/picorv32) from abroad. It fully implements the RV32IMC instruction set and can be flexibly configured into various combinations such as RV32E, RV32I, RV32IC, RV32IM, and RV32IMC. In addition, retroSoC also includes many open-source peripheral modules, such as UART, SPI, I2C, GPIO, and PWM, greatly enhancing the board's demonstration and application potential.



!!! warning "Notes"
    Overall, the board's main control chip is roughly equivalent in functionality and performance to ST's F1 mid-to-low-end series. However, due to possible software and hardware errors, the board is currently intended only for embedded prototyping (e.g., internal testing, participation in competitions), and **must not be used in actual production environments**.



## Chip Introduction

### Hardware Architecture

| Feature            | Description     |
| :----------------- | :-------------- |
| **Processor Core** | PicoRV32        |
| **Instruction Set Architecture** | RISC-V rv32imac |
| **Operating Frequency** | 72MHz       |

### Memory System

| Type          | Capacity | Address Range               |
| :------------ | :------- | :-------------------------- |
| **On-chip**   | 128KB    | `0x30000000` - `0x3001FFFF` |
| **External**  | 8MB      | `0x40000000` - `0x407FFFFF` |
| **SPI Flash** | 16MB     | `0x00000000` - `0x00FFFFFF` |

### Peripheral Modules

The project includes a rich set of peripheral driver modules:

#### Communication Interfaces

*   **SYS_UART**: standard serial communication
*   **HP_UART**: high-performance serial communication
*   **SPI**: standard SPI interface
*   **I2C**: I2C bus interface
*   **PS2**: PS2 keyboard/mouse interface

#### Storage and Control

*   **GPIO**: 16 general-purpose input/output lines
*   **PWM**: 4 pulse-width modulation outputs
*   **Timer**: 2 timers
*   **Flash**: SPI Flash controller
*   **PSRAM**: external PSRAM controller

#### Others

*   **RNG**: random number generator

*   **ArchInfo**: system architecture information



## Board Introduction

![board](../../../res/img/brd/starry-sky-c/v2.0/board1.webp)

The peripheral interfaces of the StarrySky C2 Pi are described below:

*   **System**:
	*   1 power switch, red power indicator LED
	*   1 Type-C power interface (also serves as the SoC's UART debug interface)
	*   1 drag-and-drop programmer: HFP-LINK
*   **SoC**:
	*   1 72 MHz active crystal oscillator
	*   1 active crystal oscillator pad position
	*   1 UART debug interface, using a CP2102 for protocol conversion
	*   1 reset button
	*   1 8MB PSRAM
	*   1 16MB SPI Flash
	*   1 PS2 interface
	*   1 SPI color screen
	*   2 IO pin breakouts
