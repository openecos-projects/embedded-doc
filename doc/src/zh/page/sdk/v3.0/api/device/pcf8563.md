# PCF8563 RTC

I2C 日历时钟芯片，提供秒/分/时/日/星期/月/年字段。

- 头文件：`ecos/device/pcf8563.h`
- 总线：I2C
- 示例：`examples/peripherals/i2c/pcf8563`

## 类型与常量

```c
#define ECOS_PCF8563_I2C_ADDRESS 0x51u

typedef struct {
    ecos_i2c_id_t i2c;
    uint8_t address;
} ecos_pcf8563_config_t;

typedef struct {
    ecos_pcf8563_config_t config;
    uint8_t initialized;
} ecos_pcf8563_t;

typedef struct {
    uint8_t second;   /* 0-59 */
    uint8_t minute;   /* 0-59 */
    uint8_t hour;     /* 0-23 */
    uint8_t day;      /* 1-31 */
    uint8_t weekday;  /* 0-6 */
    uint8_t month;    /* 1-12 */
    uint8_t year;     /* 0-99，相对 2000 年的偏移 */
} ecos_pcf8563_time_t;

#define ECOS_PCF8563_CONFIG_DEFAULT { ECOS_I2C_DEFAULT, ECOS_PCF8563_I2C_ADDRESS }
```

## 函数

```c
ecos_err_t ecos_pcf8563_init(ecos_pcf8563_t *rtc,
                             const ecos_pcf8563_config_t *config);
ecos_err_t ecos_pcf8563_deinit(ecos_pcf8563_t *rtc);
ecos_err_t ecos_pcf8563_get_time(ecos_pcf8563_t *rtc, ecos_pcf8563_time_t *time);
ecos_err_t ecos_pcf8563_set_time(ecos_pcf8563_t *rtc,
                                 const ecos_pcf8563_time_t *time);
```

| 函数 | 说明 |
| --- | --- |
| `ecos_pcf8563_init()` | 仅 probe 设备，不触碰 RTC 寄存器 |
| `ecos_pcf8563_deinit()` | 反初始化句柄 |
| `ecos_pcf8563_get_time()` | 读取当前日期时间 |
| `ecos_pcf8563_set_time()` | 设置日期时间 |

## 使用示例

```c
#include "ecos/device/pcf8563.h"
#include "ecos/driver/i2c.h"
#include "ecos/log.h"

#define LOG_TAG "rtc"

void read_clock(void)
{
    ecos_pcf8563_t rtc;
    ecos_pcf8563_time_t now;
    const ecos_pcf8563_config_t config = ECOS_PCF8563_CONFIG_DEFAULT;

    ecos_i2c_init(ECOS_I2C_DEFAULT, &(const ecos_i2c_config_t)ECOS_I2C_CONFIG_DEFAULT);
    ecos_pcf8563_init(&rtc, &config);

    if (ecos_pcf8563_get_time(&rtc, &now) == ECOS_OK)
        (void)ECOS_LOGI(LOG_TAG, "20%02u-%02u-%02u %02u:%02u:%02u",
                        now.year, now.month, now.day,
                        now.hour, now.minute, now.second);
}
```

## 注意事项

- `init` 只 probe 设备，不触碰 RTC 寄存器（不会破坏正在走时的时钟）。
- 时间字段为十进制语义，驱动内部完成 BCD 转换；`year` 是相对 2000 的偏移。
- 片上 RTC 的计数器/闹钟接口是另一套 IP，见 [RTC 驱动](../driver/rtc.md)。
- 通用 I2C 接口见 [I2C 主机驱动](../driver/i2c.md)。
