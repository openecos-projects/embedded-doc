# 板卡介绍

## 项目概述

StarrySkyT1 Pico 是一款面向 RISC-V SoC 学习和嵌入式原型开发的开发板。**板卡配备 32 MB SDRAM、16 MB SPI Flash、USB 转 UART 电路，以及 GPIO、I2C、QSPI 和 JTAG 扩展接口**，可用于串口通信、按键控制、存储器读写和外设扩展等实验。

板卡通过 Type-C 接口供电，并使用 CP2102 将主控 UART 转换为电脑可识别的虚拟串口。板载 LED 和按键提供基础的输入输出功能，两组 IO 排针用于连接外部模块，JTAG/Flash 排针用于引出调试和存储器访问所需的信号。

本文根据 V0.1 硬件工程和原理图介绍板卡组成及接口连接。



## 芯片介绍

### 硬件架构

板卡以 U1 主控为核心，由处理器、存储接口、通信接口及配套的时钟、电源和复位电路组成。**主控通过独立的 Flash 接口连接非易失性存储器，通过 SDRAM 接口连接运行内存，并通过 UART、I2C、QSPI 和 GPIO 与外部设备交换数据。**

| 项目 | 说明 |
| :--- | :--- |
| **主控芯片** | U1，负责程序执行、存储器访问及外设控制 |
| **处理器架构** | RISC-V，外设通过主控对应接口连接 |
| **外部时钟** | OSC1，20 MHz 有源晶振，连接主控第 126 脚的时钟输入 |
| **存储接口** | 1 组板载 SPI Flash 接口和 1 组 16 位 SDRAM 接口 |
| **通信接口** | UART、I2C 和 QSPI，其中 UART 连接板载 USB 转串口电路 |
| **GPIO 组织** | GPIOA、GPIOB、GPIOC、GPIOD 共 4 组，每组 8 路，共 32 路 |
| **调试接口** | 4 线 JTAG，通过 H3 引出 TCK、TMS、TDI、TDO |
| **IO 电压** | 3.3 V，为主控 IO 供电，并确定外部接口的逻辑电平 |
| **核心电压** | 1.2 V，与 IO 电源分别供电 |
| **复位输入** | `RST_N_I`，连接主控第 123 脚，低电平有效 |
| **启动选择** | `BOOT_SEL`，连接主控第 124 脚，通过板上电阻设置默认电平 |

#### 主控与存储器

* **Flash 通路**：U1 通过 `FLASH_CS0`、`FLASH_CLK`、`FLASH_MOSI` 和 `FLASH_MISO` 连接 U10。该通路用于访问板载 16 MB SPI Flash，相同信号同时引到 H3 排针。
* **SDRAM 通路**：U1 通过 16 根数据线、13 根地址线、2 根 Bank 地址线，以及时钟、片选和读写控制信号连接 U6。地址信号用于选择存储位置，数据线用于传输内容，DQM 信号用于屏蔽对应字节的数据操作。

两组存储接口分别连接 Flash 和 SDRAM。Flash 用于保存掉电后仍需保留的内容，SDRAM 用于保存运行期间的数据；二者的容量和用途见下文“内存系统”。

#### 通信与扩展连接

* **UART 通路**：U1 的 UART 连接 U11（CP2102-GMR），CP2102 再连接 USB1 的 D+、D-，形成 USB 转串口链路。
* **I2C、QSPI 通路**：主控相应信号引到 U2 排针，用于连接外部器件。QSPI 提供时钟、片选和 4 根数据线，与板载 Flash 使用的 `FLASH_*` 接口相互独立。
* **GPIO 通路**：4 组 GPIO 分布在 U2、U3 两组扩展排针上，其中 `gpiod4` 同时连接用户 LED，`gpioa7` 同时连接用户按键。
* **JTAG 通路**：主控的 `DBG_TCK`、`DBG_TMS`、`DBG_TDI` 和 `DBG_TDO` 引到 H3，供外部调试设备连接。

#### 时钟、电源与系统控制

* **时钟来源**：OSC1 提供 20 MHz 外部时钟，通过 `OSC_CLK_20M_I` 接入主控。该数值表示晶振输出频率，主控内部各模块的运行频率由芯片时钟设计决定。
* **供电结构**：USB1 的 5 V 输入接入 `VCC_5V`，U4、U5 两颗 RT2515HGSP 分别产生 3.3 V 和 1.2 V。3.3 V 为主控 IO、Flash 和 SDRAM 等电路供电，1.2 V 为主控核心供电；电源引脚附近配置去耦电容。
* **复位电路**：`RST_N_I` 通过 R27 上拉至 3V3，并连接 C47 和复位按键 SW3。按键闭合时将复位信号拉低，释放后由上拉电阻恢复高电平。
* **启动配置**：`BOOT_SEL` 通过 R30（10 kΩ）默认下拉，R29 为预留上拉位置，标注 NC，表示默认不装。当前原理图采用电阻配置启动选择，未设置独立的 BOOT 拨动开关。

以上为原理图可确认的硬件连接。处理器核型号、完整指令集扩展、流水线和缓存配置，以及 BOOT_SEL 各电平对应的启动地址，需要结合主控芯片设计资料确定。

### 内存系统

| 类型 | 型号 | 容量 | 连接方式 |
| :--- | :--- | :--- | :--- |
| **SPI Flash** | W25Q128JVSIQ | 128 Mbit（16 MB） | `FLASH_CS0`、`FLASH_CLK`、`FLASH_MOSI`、`FLASH_MISO` |
| **外部 SDRAM** | MT48LC16M16A2P-6A:G | 256 Mbit（32 MB） | 16 位数据总线，13 根地址线和 2 根 Bank 地址线 |

* **SPI Flash**：掉电后仍可保存数据，用于存放固件和其他持久化数据。
* **SDRAM**：用于保存程序运行中的数据，掉电后内容丢失。使用前需要初始化 SDRAM 控制器，并配置时序和刷新参数。
* **地址映射**：Flash、SDRAM 和片上 RAM 在处理器地址空间中的位置由 SoC 和链接脚本决定，存储器容量不能直接作为其访问地址。

### 外设模块

#### 通信接口

* **UART**：系统串口，通过板载 CP2102 转换为 USB 虚拟串口，用于输出日志和收发数据。
* **I2C**：提供 `I2C_SCL` 和 `I2C_SDA`，可通过 IO 排针连接传感器、EEPROM 等外部器件。
* **QSPI**：提供时钟、片选和 4 根数据线，可通过 IO 排针连接外部 SPI/QSPI 器件。

#### 存储与控制

* **GPIO**：GPIOA、GPIOB、GPIOC、GPIOD 共 4 组，每组 8 路，共 32 路通用输入输出。
* **Flash 接口**：连接板载 W25Q128。
* **SDRAM 接口**：连接板载 32 MB SDRAM，包含地址、数据、片选、时钟和数据屏蔽信号。

#### 调试与系统控制

* **JTAG**：提供 TCK、TMS、TDI、TDO，用于连接支持该 SoC 的调试器。
* **复位**：低电平有效，按下复位键后主控进入复位状态。
* **BOOT_SEL**：启动地址选择信号，通过板上电阻配置默认电平。



## 板卡介绍

![StarrySkyT1 Pico 板卡功能介绍](板卡功能介绍.png)

* **系统**：1 个 Type-C 供电/串口接口、1 个电源指示灯，以及 3.3 V、1.2 V 电源电路。
* **主控与存储**：1 个主控芯片、1 个 20 MHz 有源晶振、1 个 32 MB SDRAM 和 1 个 16 MB SPI Flash。
* **用户交互**：1 个复位按键、1 个用户按键和 1 个用户 LED。
* **通信与扩展**：1 路 USB 转 UART、2 组 2x14 IO 排针，以及 1 组 2x6 JTAG/Flash 排针。

### UART 调试接口

板载 USB 转串口芯片为 CP2102-GMR，主控 `UART_TX` 连接 CP2102 的接收端，主控 `UART_RX` 连接 CP2102 的发送端。CP2102 的 USB 数据线连接 Type-C 接口，供电脑与主控进行串口通信。**该 Type-C 接口提供供电和串口通信，板卡没有集成 HFP-LINK 拖拽式烧录器。**

### 按键与指示灯

| 功能 | 器件位号 | 信号 | 主控连接 | 状态说明 |
| :--- | :--- | :--- | :--- | :--- |
| **电源指示灯** | LED1 | 3V3 电源 | 无 GPIO 控制 | 3V3 供电正常时点亮 |
| **用户 LED** | LED2 | `LED0` | `gpiod4`，第 97 脚 | GPIO 输出低电平点亮，高电平熄灭 |
| **用户按键** | SW1 | `BUTTON0` | `gpioa7`，第 72 脚 | 松开为高电平，按下为低电平 |
| **复位按键** | SW3 | `RST_N_I` | 第 123 脚 | 按下拉低复位信号，释放后恢复高电平 |

用户 LED 通过 R28 接到 3V3，GPIO 输出低电平时形成电流通路，因此采用低电平点亮。用户按键通过 R3 上拉到 3V3，按下后接地。LED2 是器件位号，LED0 是主控控制信号的名称，对应 `gpiod4`；表中的第 97 脚和第 72 脚为芯片封装编号。上述状态根据原理图连接关系说明。

### 板载存储器

* **SPI Flash**：板载 W25Q128 使用单线 SPI 接法，IO2、IO3 通过电阻上拉。
* **SDRAM**：MT48LC16M16A2P-6A:G 采用 16 位数据总线，配套 `sdram_addr0-12`、`sdram_ba0-1`、`sdram_dqm0-1` 及控制信号，由主控提供 SDRAM 时钟。

注意：板载 Flash 与 IO 排针上的 QSPI 是两组独立接口。



## 接口信号

### JTAG 与 Flash 排针

| 奇数脚 | 信号 | 偶数脚 | 信号 |
| :--- | :--- | :--- | :--- |
| 1 | 3V3 | 2 | FLASH_MOSI |
| 3 | DBG_TDO | 4 | GND |
| 5 | DBG_TDI | 6 | FLASH_CLK |
| 7 | DBG_TMS | 8 | FLASH_MISO |
| 9 | DBG_TCK | 10 | 3V3 |
| 11 | GND | 12 | FLASH_CS0 |

* **JTAG**：TCK 为时钟，TMS 为模式选择；TDI、TDO 的输入输出方向以主控为参照。
* **Flash**：MOSI 为主机发送、Flash 接收的数据线；MISO 为 Flash 输出、主机接收的数据线。
* **3V3**：连接板卡 3.3 V 电源网络。
