# 开发入门
## 项目概述

StarrySky-T1 是一款面向 RISC-V SoC 学习、嵌入式原型验证的开发板。板卡以 U1 主控芯片为核心，配套外部 SDRAM、SPI Flash、I2C EEPROM、USB、以太网、UART、JTAG 和通用 IO 接口。配套软件为 [ECOS-SDK](https://github.com/openecos-projects/embedded-sdk)，当前使用 `2.1-dev` 分支中的 `board/StartySkyT1` 板级支持包。


## 芯片介绍

### 硬件架构

| 项目           | 说明                                 |
| :------------- | :----------------------------------- |
| **处理器核心** | RISC-V 32 位处理器                   |
| **指令集架构** | RISC-V `rv32imc_zicsr_zifencei`      |
| **工作频率**   | 20 MHz（SDK 默认 `CPU_FREQ_MHZ=20`） |
| **目标架构**   | `riscv-none-elf`，`ilp32` ABI        |
| **外部时钟**   | OSC1，20 MHz                         |

### 内存系统

| 类型              | 容量           | 地址范围                    | 说明                                                       |
| :---------------- | :------------- | :-------------------------- | :--------------------------------------------------------- |
| **片上 DSRAM**    | 16 KB          | `0x01800000` - `0x01803FFF` | SDK 默认链接脚本中的数据、BSS、堆和栈区域                  |
| **片上 ISRAM**    | 16 KB 测试区域 | `0x01000000` 起             | SDK 头文件定义的测试区域，当前默认链接脚本未将应用放置于此 |
| **SPI Flash XIP** | 16 MB          | `0x20000000` - `0x20FFFFFF` | 程序代码和只读数据默认在此执行                             |
| **外部 SDRAM**    | 32 MB          | `0x80000000` - `0x81FFFFFF` | 16 位数据总线，需先初始化 SDRAM 控制器                     |

### 外设模块

当前 SDK 的 StartySkyT1 板级支持包包含以下驱动：

#### 通信接口

* **SYS_UART**：系统串口，默认波特率 115200
* **I2C0**：I2C 主机轮询驱动
* **QSPI0**：QSPI 主机驱动，可连接板载 W25Q128 Flash

#### 存储与控制

* **GPIO**：4 组 GPIO，每组 8 个引脚，共 32 个 GPIO
* **SDRAM**：32 MB 外部 SDRAM 初始化驱动
* **Timer0**：定时器轮询和周期中断驱动
* **CLINT**：`mtime`、`mtimecmp` 计时器访问驱动
* **PLIC**：机器模式外部中断分发，支持 GPIO 和 Timer0 中断

#### 板载硬件但当前 SDK 未纳入 T1 板级驱动

* **USB**：板载 CH374T USB 控制器
* **以太网**：板载 CH395F 以太网控制器
* **I2C EEPROM**：板载 AT24C64D 器件连接在 I2C 总线上，但当前板级目录未提供专用 EEPROM 设备驱动
* **HFP-LINK**：板载下载器由独立 CH32V103C8T6 控制，下载工具链不属于 T1 应用驱动

### 主要寄存器基地址

| 外设             | 基地址       |
| :--------------- | :----------- |
| **UART0**        | `0x10010000` |
| **I2C0**         | `0x10030000` |
| **QSPI0**        | `0x10040000` |
| **GPIO0**        | `0x10060000` |
| **Timer0**       | `0x10080000` |
| **CRU**          | `0x100A0000` |
| **SDRAM 控制器** | `0x100B0000` |
| **CLINT**        | `0x02000000` |
| **PLIC**         | `0x0C000000` |

以上地址来自 ECOS-SDK `board/StartySkyT1/board.h`，裸机程序进行寄存器访问时应优先使用 SDK 提供的 HAL 接口，不建议在应用中直接复制寄存器定义。

### 板载存储器型号

| 器件           | 型号                 | 容量              | 连接方式                                       |
| :------------- | :------------------- | :---------------- | :--------------------------------------------- |
| **SDRAM**      | MT48LC16M16A2B4-6A:G | 256 Mbit（32 MB） | 16 位数据总线，配套地址、Bank、控制和 DQM 信号 |
| **SPI Flash**  | W25Q128JVSIQ         | 128 Mbit（16 MB） | QSPI 接口：CS、CLK、D0-D3                      |
| **I2C EEPROM** | AT24C64D-SSHM-T      | 64 Kbit（8 KB）   | I2C_SCL、I2C_SDA                               |

## 板卡功能

板卡图待补充

### 电源

* 板上有多处 USB Type-C 接口，电源网络包含 USB_5V 和 USB1_VCC；连接时应按接口旁的丝印区分用途。
* U4、U5 为 RT2515HGSP 电源芯片，分别生成 3V3 和 1V2 电源。
* 板卡提供电源指示灯 LED1。
* SW2 为电源开关。
* 主控芯片使用 3.3 V IO 电源，并使用 1.2 V 核心电源；上电前不要向 IO 排针直接输入超过 3.3 V 的电压。

### 通信与扩展

* **UART**：CP2102-GMR 将主控 UART 转换为 USB 虚拟串口，信号为 UART_TX/UART_RX；对应接口用于串口调试。
* **USB**：板载 USB Type-C 接口连接 CH374T USB 控制器；具体 USB 工作模式由软件和芯片配置决定。
* **下载链路**：标注为 `LINK` 的接口连接 HFP-LINK；标注为 `USB` 的接口用于 USB 控制器或其他 USB 功能。具体接口用途以板卡丝印和当前硬件版本为准。
* **以太网**：CH395F 以太网控制器连接 HR911105A 网络变压器和 RJ45 接口，带 ETH_LED0、ETH_LED1 指示信号。
* **JTAG**：IO 页提供 4 线 JTAG 信号，另有独立 IOJTAG 排针。
* **IO 排针**：U7 为 PZ2.54-2*20 双排排针，提供 2 组 20 针的 3.3 V IO 扩展。

### 按键与指示灯

* **RST**：主控复位按键，按下后触发 RST_N。
* **BUTTON0、BUTTON1**：连接主控通用输入，可用于用户交互测试。
* **LED0、LED1**：连接主控通用输出，可用于程序运行状态指示。
* **BOOT_SEL**：启动地址选择信号，用于选择主控启动方式；具体有效电平和启动地址以 SoC 设计及 SDK 说明为准。
* **FLASH_SEL**：Flash 通路选择信号，用于 HFP-LINK 与主控 Flash 接口之间的切换。

## 接口信号

### IO 排针

U7 为 2.54 mm 间距的 2x20 排针。原理图中引出的主要信号包括：

* `gpioa2`、`gpioa3`、`gpioa4`、`gpioa5`、`gpioa6`、`gpioa7`
* `gpioc6`、`gpioc7`
* `gpiod0` 至 `gpiod7`
* `I2C_SCL`、`I2C_SDA`
* `QSPI_CLK`、`QSPI_CS0`、`QSPI_DATA0` 至 `QSPI_DATA3`
* `DBG_TCK`、`DBG_TDI`、`DBG_TDO`、`DBG_TMS`
* `3V3` 和 `GND`

使用 IO 排针时，应以板卡上的丝印和原理图中的 U7 引脚编号为准。不同 SoC 软件版本可能对 GPIO 复用功能有不同定义。

### JTAG 排针

IO 页面中的 IOJTAG 接口引出：

| 信号      | 说明           |
| :-------- | :------------- |
| `DBG_TCK` | JTAG 时钟      |
| `DBG_TDI` | JTAG 数据输入  |
| `DBG_TDO` | JTAG 数据输出  |
| `DBG_TMS` | JTAG 模式选择  |
| `3V3`     | 目标板电源参考 |
| `GND`     | 地             |

## 上电与基础测试

1. 确认板卡没有短路，电源开关处于关闭状态。
2. 使用 USB Type-C 数据线连接板卡和 PC，优先选择标注为电源、串口或 `LINK` 的对应接口，并确认线缆具有供电能力。
3. 打开 SW2，观察红色电源指示灯 LED1 是否点亮。
4. 按下并释放 RST 按键，观察串口终端是否有启动输出。
5. 需要测试 UART 时，在 PC 端选择 CP2102 对应的串口，串口参数按照当前 SDK 示例配置；常见配置为 115200、8 数据位、无校验、1 停止位。
6. 需要测试外部存储器时，分别运行 SDRAM、SPI Flash 和 I2C EEPROM 的读写测试，不要仅依据串口输出判断存储器已经可用。

## 开发流程

### 开发环境配置

1. 安装 ECOS-SDK 及其依赖，并完成环境变量配置。

2. 在 SDK 外部创建自己的工程目录，不要直接修改 SDK 安装目录下的模板文件。

3. 使用 `ecos init_project` 创建工程，并将目标板指定为 `t1`。`t1` 是 SDK 命令行使用的板卡别名，`StartySkyT1` 是仓库中的 BSP 目录名。例如：

   ```bash
   ecos init_project hello -name t1_hello -target t1
   cd t1_hello
   ```

4. 运行 `make menuconfig` 配置工程。T1 板卡默认配置为 20 MHz CPU、115200 波特率和 16 KB DSRAM；GPIO、Timer、CLINT、SDRAM、I2C、QSPI 等驱动默认关闭，需要使用时手动打开。

   SDK 已为 T1 提供 `hello`、`gpio`、`gpio_interrupt`、`timer`、`timer_interrupt`、`clint`、`plic`、`sdram`、`i2c_scan`、`i2c_eeprom`、`qspi_psram`、`isram`、`asm_hello` 和 `asm_gpio` 等模板，可直接通过 `ecos init_project <模板名> -target t1` 创建。

5. 编译工程：

   ```bash
   make -j$(nproc)
   ```

   正常情况下，固件文件位于 `build/` 目录，包括 ELF 调试文件、BIN 二进制文件和反汇编文本。普通 C 工程使用 `sections.lds`，程序代码默认链接到 Flash XIP 地址 `0x20000000`，数据和栈使用 16 KB DSRAM。

### HAL 接口

T1 的板级驱动按照 ECOS-SDK HAL 接口实现。开发应用时建议使用以下接口族：

* `hal_sys_uart_*`：系统串口初始化、收发
* `gpio_hal_*`：GPIO 方向、输入输出和复用配置
* `hal_i2c_*`：I2C0 主机读写
* `hal_qspi_*`：QSPI0 读写和命令操作
* `hal_timer_*`、`hal_delay_ms()`：Timer0 和延时
* `hal_clint_*`、`hal_sys_tick_*`：CLINT 计时和系统滴答
* `hal_intr_*`：PLIC 中断初始化、申请、使能和释放

直接访问寄存器适合底层调试，不建议作为普通应用的默认写法。特别是 GPIO 复用和输入输出配置，应通过 HAL 接口完成。

### 基础测试建议

推荐按以下顺序验证板卡：

1. **串口测试**：启用 SYS_UART，连接 CP2102 对应串口，运行串口输出示例。
2. **GPIO 测试**：启用 GPIO，使用板载 LED0、LED1 或 BUTTON0、BUTTON1 进行输入输出测试；具体 GPIO 复用以原理图网络名和 SDK 示例为准。
3. **Timer/CLINT 测试**：先测试 Timer0 轮询延时，再测试 Timer0 中断和系统滴答。
4. **SDRAM 测试**：启用 SDRAM 驱动，先调用初始化函数，再对 `0x80000000` 起始的 32 MB 区域进行读写测试。
5. **Flash/QSPI 测试**：启用 QSPI 驱动，测试板载 W25Q128 的设备识别、读写和擦除操作。
6. **I2C 测试**：启用 I2C0，连接板载 AT24C64D 或外部 I2C 器件进行读写测试。当前 SDK 提供 I2C 主机驱动，但没有单独的 AT24C64D 设备层封装。

### 固件下载与启动

板卡使用板载 HFP-LINK 辅助下载。HFP-LINK 由 U14（CH32V103C8T6）实现，并通过 USB 与 PC 通信；其 SPI 信号通过 Flash 通路选择电路连接到主控 Flash 接口。

使用 SDK 提供的 `ecos-flash` 脚本时，建议按以下顺序操作：

1. 编译生成 `build/retrosoc_fw.bin` 或工程配置对应名称的 `.bin` 文件。

2. 使用 USB 数据线连接板载 HFP-LINK 接口与 PC。

3. 根据板卡丝印设置 `BOOT_SEL` 和 `FLASH_SEL`，使 Flash 通路连接到 HFP-LINK。

4. 在工程目录执行：

   ```bash
   ecos-flash
   ```

   SDK 脚本默认查找 `/run/media/$USER/YSYX-HFPLnk` 挂载目录，并将 BIN 文件复制到下载器。

5. 下载完成后断开 HFP-LINK，切换 `FLASH_SEL` 到主控侧，设置正常启动状态。

6. 重新上电或按下 RST，打开 UART 串口终端确认程序启动。

`BOOT_SEL`、`FLASH_SEL` 的拨动方向和有效电平必须以板卡丝印、下载工具版本及 SoC 启动设计为准；首次操作建议先断电，再改变开关状态。
