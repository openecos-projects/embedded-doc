# 开发入门

StarrySky-L4 是一款面向 RISC-V SoC 学习、嵌入式原型搭建和外设实验的开发板。**板卡配备 16 MB SPI Flash、8 MB PSRAM、8 KB EEPROM，以及 USB 转串口、HFP-LINK 下载器、四位数码管、温湿度传感器、蜂鸣器、用户按键和 LED**，并提供 IO 扩展排针、SPI TFT 屏幕接口和 ESP-01S 模块接口。
对于刚接触这块板卡的同学，可以先从三个部分认识它：主控负责执行程序，存储器负责保存固件和运行数据，板上的按键、显示器件和传感器负责输入输出。电脑与板卡之间通过 Type-C 连接，串口通信和板载下载器共用这个接口，由 LINK 开关选择连接通路。



## 芯片介绍
### 硬件架构

板卡以 **U2 主控芯片**为核心，外围包括存储器、通信接口、输入输出器件，以及配套的电源、时钟和复位电路。**U2 是运行用户程序的主控；U17 是 HFP-LINK 下载器使用的 CH32V103C8T6。** 两颗芯片各自承担不同任务，阅读原理图时需要按位号区分。位号就是原理图和 PCB 上用来识别器件的编号。

| 项目           | 说明                                                         |
| :------------- | :----------------------------------------------------------- |
| **主控芯片**   | U2，工程封装名称为 `ECOS_SoC1`，共 128 脚                    |
| **处理器架构** | RISC-V                                                       |
| **外部时钟**   | OSC1 提供 25 MHz 时钟，OSC4 提供 12.288 MHz 时钟             |
| **核心选择**   | 5 路 `CORE_SEL_0`～`CORE_SEL_4`，通过 U3 拨码开关设置        |
| **时钟配置**   | `PLL_EN` 和 `CLK_CFG_0`～`CLK_CFG_2`，通过板上电阻配置       |
| **GPIO 分组**  | 本封装引出 GPIO0 的 32 路、GPIO1 的 22 路、GPIO2 的 12 路，共 66 路 GPIO 引脚 |
| **存储连接**   | 独立 Flash 信号连接板载 SPI Flash；部分 GPIO 复用为 PSRAM 接口 |
| **串口连接**   | 专用 UART 连接 CP2102；GPIO0_25、GPIO0_26 可复用为 UART1，连接 ESP-01S 接口 |
| **复位输入**   | `RST_N_I`，主控第 128 脚，低电平有效，由复位监控电路控制     |
| **电源**       | 主控核心使用 1.2 V，IO 使用 3.3 V                            |

表中的 GPIO 数量指主控封装提供的引脚数量，并不表示这些引脚全部放在扩展排针上。本板 U10 扩展排针实际引出 **29 路 GPIO**，其中部分还与板载器件共用。

#### 主控与存储器

* **SPI Flash 通路**：U2 的 Flash 信号先进入 U14 切换芯片，再连接 U5 Flash。U14 用于选择由主控还是由 HFP-LINK 访问这颗 Flash。
* **PSRAM 通路**：U11 连接 GPIO0_0、GPIO0_2～GPIO0_5 和 GPIO0_7，分别承担片选、四根数据线和时钟的功能，用于扩展运行数据存储空间。
* **EEPROM 通路**：U26 通过 I2C 连接 GPIO0_27、GPIO0_28，用于保存设置参数等少量数据；温湿度传感器也接在这两根线上。

Flash 和 EEPROM 都能在断电后保留数据，PSRAM 则用于运行期间的数据存储，断电后内容会丢失。三者的详细用途见后文“板载存储器”。

#### 通信与外设连接

* **电脑通信**：Type-C 的 USB 数据线通过 U13 切换芯片连接 CP2102 或 HFP-LINK。选择 CP2102 时，电脑通过 USB 转串口链路与主控交换数据。
* **I2C 总线**：SCL 是时钟线，SDA 是数据线。AHT20 和 AT24C64D 共用这组线路，主控通过不同的器件地址选择通信对象。
* **显示输出**：板载四位数码管由 TM1650 驱动；H3 则用于连接外部 SPI TFT 屏幕，两者是独立的显示通路。
* **基础输入输出**：主控读取两个用户按键，控制两个用户 LED，并通过三极管驱动蜂鸣器。
* **无线扩展**：H1 是 ESP-01S 模块接口，连接 UART1 和 3.3 V 电源。无线功能需要外接相应模块。

#### 时钟与核心选择

板卡安装了两颗有源晶振，作用是为主控提供稳定的外部时钟。有源晶振能够直接输出时钟信号，与只提供晶体谐振元件的无源晶振不同。

| 器件     | 频率       | 主控信号           | 主控封装引脚 |
| :------- | :--------- | :----------------- | :----------- |
| **OSC1** | 25 MHz     | `OSC_CLK_25M_I`    | 119          |
| **OSC4** | 12.288 MHz | `OSC_CLK_12288K_I` | 116          |

**25 MHz 和 12.288 MHz 是外部晶振的输出频率，不能直接当作处理器的运行频率。** 处理器实际使用的时钟还与芯片内部时钟结构、PLL 和时钟配置有关。PLL 即锁相环，是芯片中用于产生或调整时钟的电路。

U3 是五位拨码开关，用于设置核心选择信号。每路信号均有下拉电阻：开关断开时为低电平，闭合时通过电阻接到 3.3 V，成为高电平。五个信号组成一个选择编码；编码对应哪个处理器核心，需要查阅该芯片的核心选择表。

| 拨码通道的引脚对 | 对应信号     | 主控封装引脚 |
| :--------------- | :----------- | :----------- |
| 1—10             | `CORE_SEL_4` | 106          |
| 2—9              | `CORE_SEL_3` | 107          |
| 3—8              | `CORE_SEL_2` | 108          |
| 4—7              | `CORE_SEL_1` | 109          |
| 5—6              | `CORE_SEL_0` | 110          |

当前原理图中，`PLL_EN` 通过 R3 下拉，R1 的上拉位置标为 NC；三路 `CLK_CFG` 也分别下拉。**电阻数值位置标注 NC，表示该位置默认不装器件。** 

#### 供电与复位

Type-C 输入的 5 V 先经过电源开关 SW9，再经过自恢复保险丝 U9，形成板上的 `VCC_5V` 电源。两颗 RT2515HGSP 进一步产生 3.3 V 和 1.2 V：

| 电源      | 产生方式                    | 主要用途                               |
| :-------- | :-------------------------- | :------------------------------------- |
| **5 V**   | Type-C 输入，经开关和保险丝 | 数码管驱动、电源芯片输入及扩展排针供电 |
| **3.3 V** | U7 稳压输出                 | 主控 IO、存储器、传感器和下载器等      |
| **1.2 V** | U8 稳压输出                 | 主控核心供电                           |

U4 为 TPS3808G01DBVR 复位监控芯片，负责监测电源并产生复位信号。主控复位按键 SW10 接到它的手动复位输入，复位输出经 R26 接到主控 `RST_N_I`。这种连接把按键复位和电源监控结合在一起。**扩展接口的 GPIO 使用 3.3 V 逻辑电平。** 排针中有 5 V 电源脚，并不表示 GPIO 可以接收 5 V 信号。


### 内存系统

| 类型          | 位号与型号                     | 容量              | 断电后是否保留 | 主要用途               |
| :------------ | :----------------------------- | :---------------- | :------------- | :--------------------- |
| **SPI Flash** | U5，W25Q128JVSIQ               | 128 Mbit（16 MB） | 保留           | 保存固件和持久化数据   |
| **PSRAM**     | U11，工程标注为 3.3 V、64 Mbit | 64 Mbit（8 MB）   | 不保留         | 存放运行数据和缓冲区   |
| **EEPROM**    | U26，AT24C64D-SSHM-T           | 64 Kbit（8 KB）   | 保留           | 保存设置参数、校准值等 |

bit 是“位”，Byte 是“字节”，8 bit 等于 1 Byte，因此 128 Mbit 对应 16 MB。工程没有给出 U11 的完整型号，也没有给出主控片上 RAM 容量及存储器地址映射，这些参数需要配套芯片资料确认。

### 外设模块
#### 通信与扩展

* **UART**：专用系统串口，连接板载 CP2102，用于电脑与主控之间的通信。
* **UART1**：通过 GPIO 复用引到 H1，可用于 ESP-01S 模块通信。
* **I2C**：连接温湿度传感器和 EEPROM，并引到 U10 扩展排针。
* **SPI / QSPI**：部分 GPIO 可复用为串行通信信号，其中 H3 使用时钟、片选和主控发送数据线连接 SPI 屏幕。
* **GPIO**：可用于按键读取、LED 控制和外部模块连接，使用时需要考虑板载共用关系。

#### 显示、采集与控制

* **四位数码管**：两颗双位数码管组成四位显示，由 TM1650 统一驱动。
* **AHT20**：数字温湿度传感器，通过 I2C 返回温度和相对湿度数据。
* **用户按键和 LED**：各两个，可用于基础输入输出实验。
* **蜂鸣器**：由 GPIO1_14 对应的 PWM 功能经三极管驱动。PWM 是脉宽调制，可输出周期性脉冲。
* **屏幕接口**：H3 提供 SPI TFT 屏幕连接所需的电源和控制信号，屏幕本体需外接。


## 板卡介绍

![StarrySky-L4 板卡功能介绍](../../../res/img/brd/starry-sky-l/v4.0/board.webp)

图中采用 V0.3_C2_3 工程对应的板卡渲染图，标注用于帮助初次使用者对照查找板上功能区。

* **系统**：1 个 Type-C 接口、1 个电源开关、1 个电源指示灯，以及 3.3 V 和 1.2 V 电源电路。
* **主控与存储**：1 个主控、2 颗有源晶振、1 个核心选择拨码开关，以及 Flash、PSRAM、EEPROM 各 1 颗。
* **通信与下载**：1 路 USB 转串口、1 个 HFP-LINK 下载器和 1 个 LINK 模式开关。
* **板载外设**：4 位数码显示、2 个用户按键、2 个用户 LED、1 个蜂鸣器和 1 个温湿度传感器。
* **扩展接口**：1 组 40 针 IO 排针、1 组 8 针 SPI TFT 接口和 1 组 8 针 ESP-01S 接口。

### Type-C、UART 与 HFP-LINK

Type-C 是板卡与电脑连接的主要接口，提供 5 V 电源和 USB 数据通路。其数据线先进入 **U13（TS3USB221ARSER）**，再根据 LINK 开关的状态选择连接 CP2102 或 HFP-LINK。

CP2102 是 USB 转串口芯片，负责在电脑的 USB 通信和主控 UART 之间转换数据。主控的 `UART_TX` 为发送信号，连接 CP2102 的 RXD；主控的 `UART_RX` 为接收信号，连接 CP2102 的 TXD。TX 表示发送，RX 表示接收，所以两个器件之间采用发送接接收的连接方式。

HFP-LINK 使用独立的 **U17（CH32V103C8T6）**。它通过 USB 接收电脑端数据，并通过 SPI 访问板载 Flash。Flash 的四根通信线经过 **U14（SN74CB3Q3257PWR）**，由它在主控和下载器之间选择访问通路。

**SW17 不只是切换 USB，它同时决定由谁访问 Flash。** U13 和 U14 共用 `FLASH_SEL` 控制信号，两种状态如下：

| `FLASH_SEL` 电平 | Type-C 数据通路 | Flash 连接对象 | 对应用途                           |
| :--------------- | :-------------- | :------------- | :--------------------------------- |
| **低电平**       | CP2102          | U2 主控        | 主控访问固件，并通过串口与电脑通信 |
| **高电平**       | HFP-LINK        | U17 下载器     | 下载器访问 Flash                   |

板上另有下载器复位按键 **SW1** 和指示灯 **LED4**。SW1 复位的是 HFP-LINK，主控复位则使用 SW10，两者不要混淆。



### 按键与指示灯

| 功能               | 器件位号    | 连接关系                          | 状态说明                                    |
| :----------------- | :---------- | :-------------------------------- | :------------------------------------------ |
| **电源指示灯**     | LED1        | 3.3 V 电源                        | 用于指示 3.3 V 电源状态，不由主控 GPIO 控制 |
| **用户 LED 0**     | LED2        | GPIO1_5，主控第 54 脚             | 输出低电平点亮，高电平熄灭                  |
| **用户 LED 1**     | LED3        | GPIO1_6，主控第 55 脚             | 输出低电平点亮，高电平熄灭                  |
| **用户按键 0**     | SW5，KEY-1  | `BUTTON0` / GPIO1_7，主控第 56 脚 | 松开为高电平，按下为低电平                  |
| **用户按键 1**     | SW22，KEY-2 | `BUTTON1` / GPIO1_8，主控第 57 脚 | 松开为高电平，按下为低电平                  |
| **主控复位按键**   | SW10，RST   | 通过 U4 控制 `RST_N_I`            | 按下触发主控复位                            |
| **下载器复位按键** | SW1         | `HFP_NRST`                        | 按下复位 HFP-LINK                           |
| **下载器指示灯**   | LED4        | U17 的 PA1，经电阻连接            | 由下载器固件控制，不能作为用户 LED 使用     |

用户 LED 的一端通过电阻接到 3.3 V，另一端连接 GPIO。当 GPIO 输出低电平时，电流能够流过 LED，所以它采用“低电平点亮”。用户按键则由上拉电阻保持高电平，按下后将对应信号接地。这里的 **LED2、LED3 是器件位号，LED0、LED1 是用户控制信号名称**。原理图中还存在位号为 LED1 的电源指示灯，查找时应同时看位号和所在功能区。


### 板载存储器
#### SPI Flash：保存固件

U5 的型号为 **W25Q128JVSIQ**，容量为 **16 MB**。它适合保存固件和其他需要长期保留的数据，断电后内容不会丢失。

本板采用标准 SPI 连接方式，发送和接收分别使用一根数据线。Flash 芯片侧的通信信号如下：

| 功能               | Flash 引脚名称 | 板上信号     | 作用                                       |
| :----------------- | :------------- | :----------- | :----------------------------------------- |
| **片选**           | CS#            | `FLASH_CS0`  | 拉低时选中 Flash，拉高时结束本次通信       |
| **时钟**           | CLK            | `FLASH_CLK`  | 为数据收发提供同步节奏                     |
| **Flash 数据输入** | DI             | `FLASH_MOSI` | 接收主控或下载器发出的命令、地址和写入数据 |
| **Flash 数据输出** | DO             | `FLASH_MISO` | 向主控或下载器返回数据和芯片状态           |

**CS 是片选（Chip Select），# 表示低电平有效。** DI、DO 分别表示输入、输出，方向以 Flash 为参照。MOSI 表示当前主机发给 Flash 的数据，MISO 表示 Flash 返回给当前主机的数据；这里的主机由 LINK 开关选择，可以是 U2，也可以是 HFP-LINK。

Flash 另外两根 IO2、IO3 引脚通过电阻上拉到 3.3 V，本板没有把它们作为四线数据通路接入主控。因此，应区分“芯片本身支持的通信模式”和“本板实际采用的连接方式”。

#### PSRAM：存放运行数据

U11 为板载 **PSRAM**，工程器件描述标注为 **3.3 V、64 Mbit，即 8 MB**。它可用于保存变量、缓存和其他程序运行数据，断电后内容会丢失。工程未填写完整料号，器件具体型号以实物和最终物料表为准。

PSRAM 可以理解为一种面向运行数据的扩展内存。本板为它连接了四根数据线，用于在主控和存储器之间传输数据：

| PSRAM 信号     | 主控 GPIO | 作用               |
| :------------- | :-------- | :----------------- |
| **CE / 片选**  | GPIO0_0   | 选择要通信的 PSRAM |
| **CLK / 时钟** | GPIO0_7   | 同步数据传输       |
| **IO0**        | GPIO0_2   | 数据线 0           |
| **IO1**        | GPIO0_3   | 数据线 1           |
| **IO2**        | GPIO0_4   | 数据线 2           |
| **IO3**        | GPIO0_5   | 数据线 3           |

这里的四根数据线表示接口传输宽度，8 MB 表示总存储容量，两者不是同一个概念。主控还提供 `PSRAM_CS1` 对应的复用信号，但当前板上仅安装一颗 U11。

#### EEPROM：保存设置参数

U26 的型号为 **AT24C64D-SSHM-T**，容量为 **8 KB**。EEPROM 是可以电擦写的非易失性存储器，适合保存设备设置、标定参数等少量数据，断电后仍能保留。

它通过 I2C 与主控连接：`GPIO0_27` 为 SCL 时钟，`GPIO0_28` 为 SDA 数据。A0、A1、A2 三根地址配置引脚都接地，对应的 **7 位 I2C 地址为 `0x50`**。WP 是写保护引脚，当前接地，允许写入。容量和地址规则可查阅 [AT24C64D 官方资料](https://www.microchip.com/en-us/product/AT24C64D)。

I2C 地址用于在总线上选择器件，不是 EEPROM 中某个字节的存储地址，也不是处理器的内存基地址。

### 四位数码管

板上使用两颗 **GS2020CR-G 双位数码管**，位号为 LED10、LED11，组合成四位显示。每个数字由若干发光段组成，驱动芯片控制不同段亮灭，就可以显示数字和部分字符。

数码管由 **U1（TM1650）**驱动。主控通过两根信号线向它发送显示数据：

| 功能     | 板上信号  | 主控连接           |
| :------- | :-------- | :----------------- |
| **时钟** | `SEG_CLK` | GPIO1_10，第 59 脚 |
| **数据** | `SEG_DAT` | GPIO1_9，第 58 脚  |

TM1650 再控制各段和各位的选通，主控不需要为四位数字逐一连接所有发光段。U1 由 5 V 供电，两根主控通信线通过电阻上拉至 3.3 V。这组两线接口与 AHT20、EEPROM 所用的 I2C 线路分开连接。

### 温湿度传感器

U15 为 **AHT20**，用于测量环境温度和相对湿度，通过 I2C 输出数字结果。它与 EEPROM 共用 GPIO0_27、GPIO0_28，板上已设置 4.7 kΩ 上拉电阻。

AHT20 的 **7 位 I2C 地址为 `0x38`**，与 EEPROM 的 `0x50` 不同，因此可以共用同一组 SCL、SDA 信号。

### 蜂鸣器

BUZZER1 型号为 **MLT-5020**，由三极管 **Q2（S8050）**驱动。主控 GPIO1_14 的 `PWM0_D0` 信号经电阻连接 Q2，Q2 再控制蜂鸣器的电流通路。这种连接由三极管承担负载驱动，主控只输出控制信号。原理图标注的 4 kHz 是蜂鸣器相关器件参数，实际声音效果还取决于驱动波形，不能当作程序默认输出频率。

| 35     | GPIO1_20 | 36     | GPIO1_21 |
| 37     | GPIO2_8  | 38     | GPIO2_9  |
| 39     | GPIO2_10 | 40     | GPIO2_11 |

**扩展排针上的部分信号同时连接板载器件。** 它们并不是额外增加的独立 GPIO：

| U10 引脚       | 共用信号                     | 已连接的功能                          |
| :------------- | :--------------------------- | :------------------------------------ |
| **12、13**     | GPIO0_28、GPIO0_27           | AHT20 和 EEPROM 的 I2C 数据线、时钟线 |
| **14、15**     | GPIO0_26、GPIO0_25           | H1 的 UART1 接收线、发送线            |
| **16、19、23** | GPIO0_24、GPIO0_12、GPIO0_16 | H3 的屏幕时钟、发送数据、片选         |
| **29**         | GPIO1_14                     | 蜂鸣器控制通路                        |

例如，GPIO1_14 用作扩展输出时，板上的蜂鸣器驱动也会接收到同一个信号；使用屏幕接口时，也不能同时让另一外设主动驱动相同的信号线。

### SPI TFT 屏幕接口 H3

H3 为 1 × 8 排母，板上丝印为 `SPI_TFT`。它提供屏幕供电、SPI 通信和显示控制信号，适合连接引脚定义相匹配的 SPI TFT 模块。

| H3 引脚 | 功能            | 板上信号 / 主控 GPIO  | 作用                             |
| :------ | :-------------- | :-------------------- | :------------------------------- |
| 1       | 地              | GND                   | 公共地线                         |
| 2       | 电源            | 3.3 V                 | 为匹配的屏幕模块供电             |
| 3       | SPI 时钟        | `SPI_CLK` / GPIO0_24  | 同步屏幕通信                     |
| 4       | SPI 发送数据    | `SPI_MOSI` / GPIO0_12 | 主控向屏幕发送数据               |
| 5       | 屏幕复位        | `LCD_RES` / GPIO0_30  | 控制屏幕复位                     |
| 6       | 数据 / 命令选择 | `LCD_DC` / GPIO0_29   | 区分发送的是显示数据还是控制命令 |
| 7       | 屏幕片选        | `SPI_CS0` / GPIO0_16  | 选择屏幕进行通信                 |
| 8       | 背光控制        | `LCD_BLK` / GPIO0_31  | 引出屏幕背光控制信号             |

该接口没有引出 MISO 接收线，当前连接主要用于主控向屏幕发送数据。不同屏幕模块的电源、背光驱动和引脚排列可能不同，选用时应逐项核对这张表。

### ESP-01S 模块接口 H1

H1 为 2 × 4 排母，板上丝印为 `ESP-01S`，用于安装相应无线模块。它连接主控 UART1，并提供 3.3 V 电源；接口本身不包含无线模块。

| H1 引脚 | 板上连接              | 说明                   |
| :------ | :-------------------- | :--------------------- |
| 1       | `UART1_RX` / GPIO0_26 | 主控接收数据的线路     |
| 2       | GND                   | 公共地线               |
| 3       | 经 R67 上拉至 3.3 V   | 模块控制引脚的上拉连接 |
| 4       | 未连接                | 原理图未接入信号       |
| 5       | 经 R68 上拉至 3.3 V   | 模块控制引脚的上拉连接 |
| 6       | 未连接                | 原理图未接入信号       |
| 7       | 3.3 V                 | 模块供电               |
| 8       | `UART1_TX` / GPIO0_25 | 主控发送数据的线路     |

本表中的发送、接收方向均以主控为参照。H1 的针脚编号以工程为准，安装模块前需要核对模块引脚和插入方向，不能只凭排母外形判断。
